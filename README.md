# Robot Vision Control System

Готова система з двох частин:

- **server/** — сервер керування, веб-інтерфейс, YOLO-детекція, координати, команди, розмітка, запуск донавчання
- **client/** — окремий клієнт для "робота", який зчитує відео з камери та надсилає кадри на сервер

## Основні можливості

- прийом відеокадрів від клієнта
- автоматичне довантаження YOLO-моделі при першому запуску
- повернення координат цілі, списку детекцій та керуючої команди
- ручний вибір цілі кліком по детекції на операторській панелі з подальшим супроводом
- видалення завантажених зображень і їх labels з інтерфейсу розмітки
- сучасний веб-інтерфейс для оператора
- завантаження зображень для розмітки
- вбудований браузерний інструмент ручної розмітки bounding boxes
- збереження датасету у форматі YOLO
- запуск донавчання з сервера
- моніторинг стану тренування
- робота "з коробки" після встановлення залежностей

## Швидкий старт

### 1. Створення середовища

#### Windows
```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

#### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
python server/app.py
```

### 3. Запуск клієнта
```bash
python client/robot_client.py --show
```

Важливо: клієнт використовує вебкамеру 0 та надсилає кадри на `http://127.0.0.1:5000`.
